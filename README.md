# Guess the Correct Word! 🎮

**Guess the Correct Word!** is an interactive and addictive web-based game designed to test your vocabulary and problem-solving skills. Players are presented with scrambled letters or blanks and must figure out the hidden word before running out of attempts. 

[Live Demo](Link-to-your-live-website-or-github-pages)

## ✨ Features
* **Interactive Gameplay:** Simple, intuitive UI for a seamless user experience.
* **Dynamic Word Generation:** Words are pulled randomly from a built-in dictionary array to ensure every game is different.
* **Hint System:** (Optional) Players can request hints to reveal letters or definitions.
* **Score Tracking:** Keeps track of your wins and mistakes.
* **Responsive Design:** Fully playable on desktop, tablet, and mobile devices.

## 🛠️ Technologies Used
* **HTML5:** For the structure of the web page.
* **CSS3:** For styling, animations, and responsive layout.
* **JavaScript (ES6):** For game logic, DOM manipulation, and event handling.

## 🕹️ How to Play
1. The game will present you with a series of blanks or a scrambled word.
2. Use your physical keyboard or the on-screen keyboard to guess the letters.
3. Guess the correct word before you exhaust your maximum number of wrong attempts.
4. Hit "Play Again" to generate a new word!
